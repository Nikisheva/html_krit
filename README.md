# AI Challenge

AI Challenge для сотрудников ОЦО и бэкофиса: знакомый процесс, идея улучшения и работающий прототип.

## Что здесь

- [`index.html`](index.html) — HTML-презентация AI Challenge в фирменном стиле КРИТ (16:9, 8 слайдов).
- [`AI Challenge.pptx`](AI%20Challenge.pptx) — та же презентация в PowerPoint для рассылки и показа. Пересборка: `python3 build_pptx.py`.
- [`Cursor для AI Challenge.pptx`](Cursor%20для%20AI%20Challenge.pptx) — обучение по инструкции «Работа с Cursor в бэк-офисе КРИТ»: 6 слайдов для ОЦО и бэкофиса. Локальная работа, план до изменений, секреты, DEV/TEST/PROD, проверка и история проекта. Пересборка: `python3 build_cursor_pptx.py`.
- [`launch-plan.html`](launch-plan.html) — оценка готовности и план запуска для организаторов.
- [`apply.html`](apply.html) — заявка на участие до 21 октября, 23:59 мск. Один человек — одна заявка. Запуск: `python3 serve.py`, затем [http://127.0.0.1:8765/apply.html](http://127.0.0.1:8765/apply.html). Сводка для организатора: [http://127.0.0.1:8765/admin.html](http://127.0.0.1:8765/admin.html) — только с компьютера, где запущен сервер. Там список заявок и выгрузка CSV. Заявки лежат локально в `data/` и в git не попадают.
- [`reglament.html`](reglament.html) — регламент AI Challenge: этапы, даты, роли, правила и недостающие материалы.
- [`Регламент AI Challenge.docx`](Регламент%20AI%20Challenge.docx) — тот же регламент в Word для рассылки.
- [`webinar.html`](webinar.html) — вебинар «Когда старая карта мира перестаёт работать» (16:9, 17 слайдов). Клавиша `N` показывает заметки спикера. Вертик на нескольких слайдах — фирменный стикер, `assets/vertik.svg`.
- [`hr-talk/index.html`](hr-talk/index.html) — доклад «Цифровые сотрудники в HR» для СПИБА и Политеха (16:9, 13 слайдов, та же схема, что у вебинара: синее поле, рельс, бейдж, Вертик на титуле). `?event=spiba` или `?event=polytech` меняет подпись площадки. `N` — заметки, `F` — полный экран. Картинки: [`hr-talk/assets/README.md`](hr-talk/assets/README.md).
- [`hr-talk/Цифровые сотрудники в HR.pptx`](hr-talk/Цифровые%20сотрудники%20в%20HR.pptx) — первая сборка доклада в PowerPoint.
- [`hr-talk/Цифровые сотрудники в HR_FINAL.pptx`](hr-talk/Цифровые%20сотрудники%20в%20HR_FINAL.pptx) — версия для выступления: та же структура, сильнее собраны слайды про тендеры, 360, кросс-функциональную схему и роль HR. Рядом лежит PDF для просмотра. Пересборка pptx: `python3 hr-talk/build_pptx.py`. Исходный pptx скрипт не перезаписывает.
- Источник стилей: `brand-tokens.css`, `storybook-static/krit-report-components.css`, шрифт Uncage, логотипы Grey/White.

## Как смотреть

1. Открыть `index.html` или `webinar.html` в браузере (удобнее через локальный сервер из этой папки). Для приёма заявок — `python3 serve.py`.
2. Листать стрелками, пробелом или кнопками «Назад / Дальше».
3. Печать → «Сохранить как PDF», если нужен файл для рассылки без HTML.
4. Для PowerPoint открыть `AI Challenge.pptx`.

## Порядок этапов

19 октября начало → 20 октября обучение → до 21 октября заявки на участие → 22 октября выдача заданий → тестовый тур до 30 октября → 6 ноября просмотр идей → 7–19 ноября MVP → 20 ноября показ.

Участие только одиночное. В заявке — 8 пунктов. Отбор идей: пять оценок 0–5 и +2 за кросс-функциональное решение. Призы: 100 / 50 / 30 тыс. ₽.
