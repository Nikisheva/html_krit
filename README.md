# Challenge

Сотруднический документ Challenge: живой процесс → новая логика → работающий MVP.

## Что здесь

- [`index.html`](index.html) — страница для рассылки в визуальном языке [krit.pro](https://www.krit.pro): шрифты UNCAGE и Inter, чёрно-белая геометрия, акцент `#389BFF`.
- `fonts/` — локальные файлы шрифтов с сайта КРИТ, чтобы страница открывалась без интернета.
- Даты не зафиксированы. Их нужно вписать только в блок **«Календарь Challenge»** в `index.html` — плейсхолдеры выделены.

## Как подготовить к отправке

1. Открыть `index.html`.
2. Заменить фразы «дата будет объявлена» в таблице календаря.
3. При необходимости уточнить FAQ-пункты, помеченные как «будет уточнено до старта».
4. Сохранить PDF через печать браузера или отправить ссылку / HTML-файл.
