# Challenge

Внутренний Challenge для сотрудников ОЦО и бэкофиса: живой процесс → новая логика → работающий MVP.

## Что здесь

- [`index.html`](index.html) — HTML-презентация в фирменном стиле КРИТ (16:9, 15 слайдов).
- Источник стилей: `brand-tokens.css`, `storybook-static/krit-report-components.css`, шрифт Uncage, логотипы Grey/White.
- Для рассылки используйте самодостаточный файл [`dist/index-client.html`](dist/index-client.html).

## Как смотреть

1. Открыть `index.html` в браузере (удобнее через локальный сервер из этой папки).
2. Листать стрелками, пробелом или кнопками «Назад / Дальше».
3. Печать → «Сохранить как PDF», если нужен файл для рассылки без HTML.

## Как подготовить к отправке

1. Вписать даты в таблицу **«Календарь Challenge»** вместо фраз «дата будет объявлена».
2. При необходимости уточнить FAQ-пункты, помеченные как «будет уточнено до старта».
3. Отправить коллегам `dist/index-client.html`, а не рабочий `index.html`.

## Порядок этапов

Workshop → Входной тест → Идея → Отбор → MVP → Demo Day
